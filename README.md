# codedbysejal — Personal Portfolio

A modern, dark-themed, single-page developer portfolio built with **React.js**, **Vite**, and **Tailwind CSS v4.1**, inspired by the elegant UI of [nadhir.dev](https://nadhir.dev/). This SPA showcases my professional experience, featured projects, and contact capabilities with animations, dark/light mode toggle, and a fully functional contact form with toast notifications.

## 🔗 Live Demo

> [https://codedbysejal.dev](https://codedbysejal.dev)

## 🚀 Features

- ⚡ Built with React.js + Vite for high performance
- 🎨 Tailwind CSS 4.1 custom theme with CSS variables and dark mode toggle
- 📱 Fully responsive design
- 🧩 Modular component architecture
- 💼 Experience, Projects, About, and Contact sections
- 📬 Contact form integration using Formspree + react-hot-toast
- 💾 Hosted on Hostinger (or mention Netlify/Vercel/GitHub Pages)
- 🌐 SEO-friendly and accessible
- 🧪 Scroll animations using Framer Motion

## 🖥️ Tech Stack

- React.js
- Tailwind CSS 4.1
- Vite
- react-hot-toast
- Framer Motion
- Formspree (for form handling)
